## 📖 Why I Built This (Kyo Banaya)

As an ambitious student and developer in India preparing for the 2030 horizon, I got tired of fragmentation. 

Every single day, I found myself constantly context-switching between 10+ disconnected apps:
- **Notion** for notes & planning
- **Linear / Trello** for task tracking
- **Habit trackers** for daily routines
- **ChatGPT** for AI advisory
- **Duolingo / Flashcards** for learning
- **Excel / Expense apps** for finances
- **Gym loggers** for physical workouts

None of these apps talked to each other. None of them knew my overarching **2030 Singularity Goal**. None of them provided a single, unified executive dashboard when I opened my laptop every morning.

So I decided to build **Operation Dhruv Tara** — my second brain, my sovereign command center, and my 360-degree AI Life Operating System. When I open this application every morning, I never need another productivity tool again.

## ⚙️ How It Was Engineered (Kese Banaya)

I architected Operation Dhruv Tara from scratch using modern, high-performance web standards:

### 1. Core Framework & Language
- **Next.js 16 (App Router + Turbopack)**: Server-side rendering, instant page transitions, dynamic route segments.
- **TypeScript 5 (Strict Mode)**: 100% type safety across all components, state stores, and data models with zero compilation errors.

### 2. Design System & Visuals
- **Custom CSS Tokens & Glassmorphism**: High-contrast dark theme (`#040408`), backdrop blur filters, glowing accent cards.
- **Three.js WebGL Neural Canvas**: 600 particle nodes with real-time mouse parallax and additive blending.
- **Framer Motion**: Smooth 60fps animations, staggered entry effects, and interactive modal transitions.

### 3. State Management & Storage
- **Zustand Store with LocalStorage Persistence (`odt.store.ts`)**: Fast, lightweight client-side state engine that keeps all data 100% sovereign and private on your device.

### 4. AI & Voice Intelligence
- **Google Gemini 1.5 Flash API**: Integrated via `@google/generative-ai` for intelligent, context-aware AI advisory.
- **Web Speech API**: Integrated voice synthesis for JARVIS audio speech output.

## 🚀 Quick Setup & Installation

### Option A: Open Official Live Web App
Click **[https://dhruv-tara-one.vercel.app/](https://dhruv-tara-one.vercel.app/)** to use the application instantly in your browser!

### Option B: Run Locally on Your System

```bash
# 1. Clone the repository
git clone https://github.com/Shyamsundar2203/Dhruv-Tara.git
cd Dhruv-Tara

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open `http://localhost:3000` in your browser.
